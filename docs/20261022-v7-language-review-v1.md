## 逐项建议

### 1. A10 末句像审核答复，建议优先处理

位置：A10，paraId `4295FB1E`。

原文：

> 构建缓存及其他基础镜像未作为本地应用标签存在的依据。

问题：否定结构叠加抽象名词，读者难以判断句子想解释什么；像在回应一次关于缓存的质疑。

建议替换为：

> 拉取日志中部分镜像层显示 Already exists，说明这些层仍保留在本地；应用镜像的两个本地标签在拉取前均已删除。

依据：`docs/v7-work/10-remove-and-pull.txt` 同时记录了两个标签移除、inspect 检查和多个 Already exists。保留这一区别，不将“删除本地标签”改写为“清除所有缓存后完整下载”。

### 2. A10 “镜像列表为空”缺少筛选范围

位置：同上，paraId `4295FB1E`。

原文：

> inspect 确认标签不存在、镜像列表为空后，才从 Registry 执行 pull。

问题：容易被读成整个引擎没有任何镜像；实际命令只筛选 memory-game6085。这里既是表达省略，也影响事实准确性。

建议：

> 通过 inspect 确认两个本地标签均不存在，并检查筛选后的镜像列表中已无 memory-game6085，再从 Registry 拉取镜像。

依据：实际日志命令为 `docker image ls --filter 'reference=*memory-game6085*'`。

### 3. A8 失败说明可以保留，去掉文档管理口吻

位置：A8，paraId `598B4170` 后半段。

原文：

问题：“健康检查曾早于应用就绪”搭配不顺；后半句讲的是如何整理交付证据。
