## 产品

- 产品名：记忆花园 / Memory Garden。
- 核心：植物主题翻牌配对，三种难度，步数、计时、配对进度，暂停/继续，重新开始，结束后提交昵称与成绩，按难度查询排行榜。
- 游戏由 Spring Boot 生成牌局并处理翻牌、匹配、步数与计时；客户端不能直接提交自报成绩。
- SQLite 保存最终成绩；运行中的牌局保存在服务器内存，服务重启后不恢复。
- 不添加账号、商城、Redis 或额外数据库服务。

## 部署

- Vue 构建为静态资源并打入 Spring Boot JAR，最终一个容器提供页面和 API。
- SQLite 文件目录挂载到 Docker 命名数据卷；镜像发布不包含数据库。
- 发布仓库账户尚未提供，先完成本地构建和部署准备，不执行对外推送。
